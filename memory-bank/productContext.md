# Product Context: DevOps Hybrid Stand

## Проблема
Нужно проходить полный цикл DevOps практик без Enterprise-среды, с ограниченным бюджетом на LLM и возможностями импортозамещения.

## Решение
Гибридное окружение из нескольких слоёв (сеть → серверы → приложения → CI/CD), где каждый слой можно включать/выключать по мере необходимости.

## Пользовательские сценарии
1. **Планирование проекта** — использовать облачную модель `deepseek-v4-flash` для верификации планов и исправления ошибок
2. **Исполнение кода/заданий** — локальная модель `qwen3.5-9b-deep` через Ollama
3. **Поиск работы** — использовать KB для построения карты навыков (skill-map.md)
4. **Изучение технологий** — писать заметки в ~/KB/technologies

## Ожидаемое поведение продукта
- Поддержка включаемых/выключаемых слоёв инфраструктуры
- Экономия бюджета через локальные модели
- Автоматический возврат к Plan mode при проблемах с Act
- Интеграция Yandex Cloud для managed-Kubernetes экспериментов
