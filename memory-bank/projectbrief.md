# Project Brief: DevOps Hybrid Stand

## Цель
Построить на одной рабочей станции мини-инфраструктуру для прохождения **полного цикла DevOps-практик** (сеть → серверы → приложения → CI/CD → наблюдаемость) с возможностью включать/отключать слои по мере необходимости.

## Scope
### Входит в проект:
- GNS3/EVE-NG для сетевого слоя
- KVM/libvirt виртуализация
- k3s/k3d для оркестрации контейнеров
- CI/CD (Jenkins + Argo CD)
- База знаний и оркестрация LLM моделей

### Не входит:
- GitLab CE (используется офисный сервер)
- Полноценные enterprise стенды

## Критерии успеха
1. Завершение планирования DevOps стендов
2. Развёртывание первого стенда (k3s в KVM)
3. Работающая база знаний для поиска работы
4. Экономия 70–85% на LLM-стоимости

## Ключевые требования
### Функциональные:
- Полноценный цикл DevOps практик
- Включение/выключение слоёв инфраструктуры
- Интеграция облачных и локальных моделей

### Нефункциональные:
- Потребление ~6–8 ГБ ОЗУ (k3s в KVM)
- Использование Ollama для локальных моделей
- Экономия бюджета на LLM (~$6/мес)
